# Assets

Images used by the READMEs. The Formula 1 photograph in `overview.png` and `data_sources.png` is from Pexels; the
logos in `data_sources.png` are those of the FastF1 project, the Technical University of Munich, and Assetto Corsa
(Kunos Simulazioni).

| file | shows | used in |
|---|---|---|
| `overview.png` | the method: F1 data, raceline predictor, minimum-time optimization, RoboRacer | [`README.md`](../README.md) |
| `architecture.png` | the network (`RacelineNet`) | [`README.md`](../README.md) |
| `tracks.png` | the 17 tracks of the dataset | [`data/README.md`](../data/README.md) |
| `data_sources.png` | the two data sources: F1 telemetry and track geometry | [`data/README.md`](../data/README.md) |
| `alignment.png` | raw telemetry being aligned to a track | [`data/README.md`](../data/README.md) |
| `prediction_barcelona.png` | output of `scripts/predict.py --plot` on a test track | [`scripts/README.md`](../scripts/README.md) |
